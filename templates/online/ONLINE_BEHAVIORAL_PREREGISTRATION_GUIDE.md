# Online Behavioral Experiments Preregistration Template (PRP-QUANT Based)

## Overview

This template is designed for preregistering online behavioral experiments in psychology and biopsychology. It is based on the PRP-QUANT (Psychological Research Preregistration-Quantitative) Template, developed by a joint task force of the APA, BPS, and DGPs.

## Purpose

Preregistration of online behavioral studies helps:
- Separate hypothesis-generating (exploratory) from hypothesis-testing (confirmatory) research
- Increase transparency and credibility of findings
- Document methodological decisions before data collection
- Reduce HARKing (Hypothesizing After Results are Known)

## Key Sections to Include

### 1. Title and Abstract
- Study title
- Brief abstract (150 words) summarizing the study

### 2. Introduction
- Background and rationale
- Research objectives
- Research questions
- Hypotheses (clearly state directional vs. non-directional)

### 3. Method

#### 3.1 Participants
- Target sample size with justification
- Power analysis details
- Inclusion criteria
- Exclusion criteria
- Recruitment method and source
- Compensation
- Stopping rule for data collection

#### 3.2 Online Platform Specifics
- Platform/software used (e.g., Qualtrics, Pavlovia, jsPsych, Gorilla, MTurk)
- Browser/device requirements
- Attention checks and quality control measures
- Bot detection methods
- Duplicate participation prevention
- Geographic restrictions (if any)
- Data quality thresholds

#### 3.3 Study Design
- Design type (between-subjects, within-subjects, mixed)
- Independent variables
- Dependent variables
- Randomization procedure
- Counterbalancing
- Blinding procedures

#### 3.4 Materials
- Stimuli description
- Questionnaires/scales used (with citations)
- Reliability and validity of measures
- Pilot testing results (if applicable)

#### 3.5 Procedure
- Step-by-step description of participant experience
- Timing of each component
- Instructions provided to participants
- Debriefing procedure

### 4. Online-Specific Considerations

#### 4.1 Technical Requirements
- Minimum browser version
- Screen size requirements
- Audio/video requirements
- Internet connection speed
- Mobile vs. desktop restrictions

#### 4.2 Data Quality Control
- Attention check questions
- Comprehension checks
- Timing checks (too fast/too slow responses)
- Straight-lining detection
- Incomplete response handling
- Failed attention check handling

#### 4.3 Participant Engagement
- Estimated completion time
- Progress indicators
- Break opportunities
- Incentive structure

### 5. Variables

#### 5.1 Measured Variables
- List all variables to be collected
- Operationalization of each variable
- Measurement scale/type
- Coding scheme

#### 5.2 Indices
- Composite scores or indices
- Calculation method for each index

### 6. Analysis Plan

#### 6.1 Data Preprocessing
- Data cleaning steps
- Outlier detection and handling
- Missing data strategy
- Transformation procedures (if any)

#### 6.2 Exclusion Criteria
- Participant-level exclusions
  - Failed attention checks
  - Incomplete responses
  - Suspicious response patterns
  - Technical issues
- Minimum data quality requirements

#### 6.3 Statistical Tests
- Primary analyses
  - Statistical test for each hypothesis
  - Assumptions to be tested
  - Planned contrasts
- Secondary analyses
- Exploratory analyses (clearly labeled)

#### 6.4 Inference Criteria
- Alpha level
- Corrections for multiple comparisons
- Effect size measures
- Confidence intervals

#### 6.5 Data Exclusion and Sensitivity
- Robustness checks
- Sensitivity analyses
- Handling of assumption violations

### 7. Other

#### 7.1 Ethical Considerations
- IRB/Ethics approval status
- Informed consent procedure
- Data privacy and anonymization
- Participant withdrawal rights

#### 7.2 Data Management
- Data storage location
- Data sharing plan
- Open science practices (preregistration, open data, open materials)

#### 7.3 Timeline
- Expected start date
- Expected completion date
- Milestones

### 8. Deviations
- How deviations from this preregistration will be documented
- Distinction between confirmatory and exploratory findings in final report

## Online Behavioral Experiment Addendum

### Platform-Specific Issues
- Cross-browser compatibility testing
- Mobile responsiveness
- Timing accuracy considerations
- Stimulus presentation precision

### Recruitment Source Considerations
- Crowdsourcing platform characteristics (e.g., MTurk, Prolific)
- Demographic representativeness
- Previous participation in similar studies
- Platform-specific quality indicators (e.g., approval rate)

### Remote Data Collection Challenges
- Lack of experimental control
- Environmental variability
- Participant multitasking
- Technical difficulties
- Mitigation strategies for each

## Notes

- Fill out as much as possible, but acknowledge uncertainty where it exists
- "Not yet decided" is an acceptable answer - document your decision-making process
- Update and document any deviations from the preregistration
- Consider using version control for your preregistration
- This template is comprehensive - adapt sections as needed for your specific study
